# SignalScope — Frontend Application

High-performance, brutalist interactive web application for forensic image authenticity verification, spatial attention heatmaps, and batch archive auditing.

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4 (Editorial Brutalist design language)
- **Animation & Physics**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Build Tool**: Vite 6

## Development Quickstart

### Prerequisites
- Node.js 18+ (Node 20+ recommended)
- Python backend running on port 8000 (`uvicorn api.server:app --port 8000`)

### Installation & Run
```bash
# 1. Install dependencies
npm install

# 2. Start the local development server (runs on port 3000)
npm run dev

# 3. Build for production (compiled into dist/ for FastAPI serving)
npm run build
```

## Features
- **Page 1: Hero & What It Does**: Interactive 4-point sparkle stars with physics, crisp brutalist typography, responsive mobile scaling.
- **Page 2: Live Forensic Lab**: Drag-and-drop single image and batch ZIP scanning, 4-layer forensic view modes (Suspicious Heatmap, Focus Areas, Sensor Noise, Light Waves).
- **Page 3: Pipeline & Architecture**: Multi-modal dual-stream breakdown with simple and technical views.
- **Page 4: Trust & Stress Lab**: Social media compression stress-test evidence, C2PA provenance audit matrix, and FAQ accordion.
